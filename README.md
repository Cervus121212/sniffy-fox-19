A program that writes one original one-line roast of your fridge (93 characters) to `entry.txt`: This fridge's only food-safety inspector is your nose, and your nose has never once said yes.

## Run it

```sh
OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
